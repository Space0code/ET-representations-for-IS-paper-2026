# SKUI / Information Society 2026 talk

**Use this one:** `SKUI2026_ET_representations.pptx` — simple 10-slide deck in the style of the SKUI 2024 talk
(red titles, logo footer, same master). Slide 10 is a backup table. Talking points: `talk_notes.md`
(also in the slide notes).

Rebuild (needs the SKUI 2024 deck as template, which is not in the repo):

    python presentation/build_deck_simple.py --template path/to/SKUI_2024_presentation.pptx

`fig1_descriptive.png` is a 600-dpi PNG render of `paper/figures/fig1_descriptive.pdf`.

Superseded first draft: `IS2026_SCAI_ET_representations.pptx` (built by `build_deck.js`).
