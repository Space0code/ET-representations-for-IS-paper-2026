# SCAI / Information Society 2026 talk

- `IS2026_SCAI_ET_representations.pptx` — 16:9 deck, 12 main slides + 2 backup slides, speaker notes with timing on every slide (~12 min talk + ~3 min Q&A).
- `build_deck.js` — regenerates the deck with pptxgenjs:
  `node presentation/build_deck.js [--fig1 PNG] [--fig2 PNG] [--out PPTX]`
- `fig1_descriptive.png` — PNG render of `paper/figures/fig1_descriptive.pdf` (600 dpi).

The slide masters `IS_DARK`, `IS_CONTENT` and `IS_TITLE_BODY` appear as layouts in PowerPoint (Home → New Slide) for adding slides in the same style.
